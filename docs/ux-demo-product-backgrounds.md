# UX demo product backgrounds

Created using the built-in image generation tool for background edits, then encoded as WebP. Original source assets are preserved. All final edited images are 1448 × 1086 pixels. Changes are scoped to the UX demo.

The iPhone and MacBook retain their existing white-background images; the hero remains unchanged. Cards, quick view, and bag thumbnails share each product's image and backdrop.
